# 🛡️ Real-Time NIDS & Port Scan Detector (`NIDS.py`)

A custom Python-based Network Intrusion Detection System (NIDS) that uses **Scapy** to monitor live network traffic, detect Port Scanning activity in real-time, and log security events.

---

## 🚀 Key Features
* **Live Traffic Sniffing:** Captures incoming IP/TCP packets in real-time without storing unneeded traffic in memory (`store=False`).
* **Port Scan Detection:** Tracks destination ports queried by unique IP addresses to identify potential reconnaissance scans (triggers alert when distinct ports > 5).
* **Automated Security Logging:** Records timestamps and alert parameters directly into `security_report.log`.
* **Colored Console Alerts:** Displays highlighted visual warnings upon threat detection.

---

## 🛠️ Built With
* **Python 3**
* **Scapy Library** (`scapy.all`)
* **Datetime Module**

---

## 📂 Repository Structure
* `NIDS.py` - Core Python script for traffic sniffing and scan detection.
* `security_report.log` - Output log file generated by the script during execution.
